## Strapi 5.52.0 (MCP server, admin tokens, REST, Content Manager)

> This is the Strapi section of a review that covered three products in one pass. The shared scoreboard, the verdict vocabulary and the method notes are in [../README.md](../README.md).

**Ten real defects, none reported upstream, none fixed on `develop` as of 2026-08-14.** Seven of them sit in the April to June 2026 MCP + admin-token feature work (PRs #26371, #25657, #26560), three are older and unrelated to that work. Seven doc bugs, all in the separate `strapi/documentation` repo, three of them stale since 2024.

### Noise, honestly

- `the-filters-button-narrows-the-list-to-published-entries.web.1`: **test defect.** The doc says the Status sort is disabled under a status filter, and it is (`ListViewPage.tsx:215-219` sets `sortable: false`); the scenario asserted an ARIA `disabled` state the doc never promised. Underneath sits an unreported a11y defect: `strapi/design-system` renders every cell as `role="gridcell"`, so the `role="grid"` table exposes no column headers and `aria-sort` is never announced.
- `the-rest-error-envelope-carries-its-documented-members.api.1`: **test defect.** Asserted the `NotFoundError` class default `"Entity not found"` on the public REST 404; that string is a constructor default the docs describe under "Throwing errors", not a promise about the endpoint. The same wire behavior is the real doc bug S15.
- `an-entry-that-fails-validation-cannot-be-bulk-published.web.1`: **environment.** The bulk-action buttons did not paint within the 10 s step budget; the screenshot 0.1 s later shows them, and a sibling scenario saw them in 354 ms. Contributing: the toolbar is committed on an untimed `requestIdleCallback` (`DescriptionComponentRenderer.tsx:50-66`).
- `the-documented-page-size-ceiling.api.1`: **environment** (S17 above).

### Against the researcher's 8 Strapi findings

All 8 confirmed. Refinements: #1's reaper is the 2021 nil-property rule, scope narrower than "all permissions vanish" (S1); #3's drop is decided in the 2022 engine (S2); #4's string workaround works, `null` is what misfires (S5); #6's operative culprit is the handler omission, not only `input-schemas.ts` (S7); #8a carries a verified escalation (S11). New beyond the write-up: S8, S9, S10, S13, S14, S15, S16 (S3 is their #2, traced to the 2022 engine rather than the MCP code).
