## Documenso 2.16.0 (v2 signing API, web signing UI)

> This is the Documenso section of a review that covered three products in one pass. The shared scoreboard, the verdict vocabulary and the method notes are in [../README.md](../README.md).

**Nine real defects and seven doc bugs.** The doc bugs share one origin: PR #2460 "feat: docs v2" (2026-02-27) published request bodies, response envelopes and an error format that the v2 API never had. A single community contributor noticed part of this and opened a stacked docs series on 2026-07-30 (#3133, #3134, #3135, #3136, #3137, #3138, #3139); as of 2026-08-15 all are open, blocked, based on each other rather than `main`. Exactly one finding was fixed after the tested tag: the rate limit (PR #3081, merged 52 minutes after v2.16.0 was cut, on `main` and on app.documenso.com, in no release).

| D10 | The v2 error response format is `{error, code, statusCode}` (getting-started). | Every tRPC-backed v2 error is `{message, code, data{code, httpStatus, appError}, issues}` (trpc-to-openapi); no v2 code path emits `error` or `statusCode`. ### Noise, honestly

- `download-an-envelope-item-in-each-documented-version.api.1`: **test defect** (D17). Two mutually exclusive assertions about one request.
- `the-editor-takes-a-recipient-and-its-role.web.1`: **test defect.** The quickstart lists four roles; two other bound pages document Assistant as a fifth that unlocks under sequential signing, and the scenario had just turned sequential signing on.

### Against the researcher's 8 Documenso findings

All 8 confirmed. Refinements: #1's PR #3136 is stacked on a non-main base and does not fix the fieldMeta wipe (D2); #2 hits all ten fieldMeta types (D2); #3 also covers edits, deletes and fields (D1); #4 is a doc bug, not a defect (D11); #5's "every API error" is too strong and #2114 already shows the envelope (D10); #6's filed edge is #3191, and the guards are unenforced during the window (D4); #7's mechanism is a query-param mismatch (D7); #8 is a 46-site pattern (D8, D9). New beyond the write-up: D3, D5, D6, D13, D14, D15, D16.
