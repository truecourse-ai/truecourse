# Getting started

Install the Slate CLI, connect your calendar, and publish your first bookable
slot.

```bash
npm install -g @slate/cli
slate connect google-calendar
slate slots publish --provider you --from 09:00 --to 17:00
```

A published slot appears on your booking page within a minute. Book it from an
incognito window to see the full customer flow, then cancel it from the
dashboard.
